# محاسبه‌گر نرخ سود مؤثر اوراق

ابزار تک‌فایلی برای محاسبه نرخ سود مؤثر (YTM) اوراق مرابحه و سلف موازی، با تقویم شمسی و تعدیل روز کاری.

این پوشه مستقل از بقیه مخزن است و هیچ وابستگی به آن ندارد.

## چه می‌کند

- محاسبه نرخ مؤثر روی تاریخ‌های واقعی میلادی با مبنای ۳۶۵ روز
- تفکیک نرخ ارائه‌شده به سازمان (بدون الحاقیه) از هزینه واقعی بانی
- حل معکوس: با دادن YTM هدف، نرخ هر رکن یا مبلغ انتشار را به‌دست می‌دهد
- تعدیل تاریخ پرداخت برای آخر هفته و تعطیلات رسمی شمسی و قمری
- انتخاب روز پرداخت در ماه و تأخیر چندروزه برای هر رکن

## فایل‌ها

| فایل | نقش |
|---|---|
| `index.html` | کل برنامه — بدون هیچ درخواست شبکه |
| `sw.js` | کش آفلاین |
| `app.webmanifest` | تعریف اپ برای نصب روی هوم‌اسکرین |
| `icon-*.png` | آیکون‌ها |

## نصب روی آیفون

صفحه را در سافاری باز کنید، سپس Share ← Add to Home Screen.
بعد از اولین بازکردن، بدون اینترنت هم کار می‌کند.

## محدودیت‌ها

تعطیلات قمری با تقویم جدولی محاسبه می‌شود و در صفحه با ◦ علامت می‌خورد. ممکن است یک تا دو روز با اعلام رسمی تفاوت داشته باشد؛ برای قرارداد نهایی تاریخ را با تقویم رسمی بررسی و اصلاحش را در کادر «تعطیلات اضافه» وارد کنید.

مبلغ هر کوپن با جابه‌جایی تاریخ تغییر نمی‌کند — فقط دیرتر یا زودتر پرداخت می‌شود.
